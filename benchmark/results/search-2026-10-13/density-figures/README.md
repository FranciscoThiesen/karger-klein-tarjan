# Five-solver search figures

Each campaign remains separate. Every family/density and measured size in each validated analysis is plotted, including losses and controls. Ratio markers use median paired ratios over repetitions, then sampling seeds, then graph seeds; runtime markers use the same nesting separately for each algorithm. Ratios of runtime medians are not substituted for paired ratios.

Error bars show the full observed individual-trial range, not a confidence interval. Sampling seeds repeat identical inputs for deterministic competitors. Connecting segments are visual guides between measured sizes, without smoothing or an estimated transition point. Ratio lines at 1 and 0.9 mark parity and a 10% lower KKT runtime; crossing a line alone is not a confirmation criterion.

Axes are logarithmic and fitted per family/density. The same group uses matching limits across the separate campaign figures. Absolute times are included to keep ratio changes in context. No call is removed for a clock flag. Warmups are retained in the source analysis but not summarized as timed observations.
